# React Practice Projects

A collection of small React projects created while learning and practicing core React concepts such as components, hooks, routing, state management, API handling, and local storage.

---

## 📂 Projects Included

### 1. amazing-todo
A simple Todo application with basic CRUD functionality.

**Concepts Used**
- Components
- State Management
- Event Handling

---

### 2. github-finder
Search GitHub users and view their profile information using the GitHub API.

**Features**
- GitHub API integration
- User search
- Local storage optimization to reduce unnecessary API calls

**Concepts Used**
- Axios
- API Calls
- useEffect
- Local Storage

---

### 3. hooks
Practice project for understanding React Hooks.

**Hooks Covered**
- useState
- useEffect

---

### 4. my-cart
A basic cart management application.

**Concepts Used**
- Props
- State
- Cart Logic
- Component Reusability

---

### 5. react-router
A demo project for learning React Router.

**Concepts Used**
- React Router
- Navigation
- Route Handling

---

### 6. todo
Intermediate-level Todo application with improved structure and functionality.

**Concepts Used**
- State Management
- Component Communication
- Conditional Rendering

---

### 7. usecontext
Practice project for learning Context API.

**Concepts Used**
- Context API
- Global State Management
- useContext Hook

---
